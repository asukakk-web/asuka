# 基于ＳｐｒｉｎｇＢｏｏｔ＋ｖｕｅ的社区健康服务系统

## 项目简介
这是一个社区管理系统，用于数据管理和可视化。作为本科毕业设计独立完成。

## 技术栈
- 后端：Spring Boot3、MyBatis-Plus、MySQL、JWT
- 前端：Vue 3、Element-UI、Axios、Vue Router

## 核心功能
- 用户登录/认证（JWT）
- 数据增删改查
- 分页查询
- 响应式界面

## 如何运行
### 后端
1. 导入SQL文件到MySQL
2. 修改application.properties中的数据库配置
3. 运行Application.java

### 前端
1. cd frontend
2. npm install
3. npm run serve
